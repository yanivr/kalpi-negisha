## מה **לא** נבדק

- קוראי מסך: NVDA עם Windows, VoiceOver עם Safari ב־iOS, TalkBack עם Chrome באנדרואיד. לא היו זמינים בסביבת הפיתוח.
- מצב forced colors במכשיר אמיתי. קיימים כללי CSS ייעודיים, אבל לא נבדקו.
- בדיקות עם משתמשים: קושי דיגיטלי, קורא מסך, קושי תפעולי. **לא בוצעו.**
- זיהוי קולי (Voice Control). התוויות גלויות וזהות לשם הנגיש, אבל לא נבדק בפועל.
- אמהרית: לא ידוע אם קיים קול דיבור במערכות ההפעלה של המשתמשים. ראו אפיון §21.4.

## מאפייני מימוש

HTML סמנטי עם header, main ו־footer, כותרת ראשית אחת, וקישור דילוג. השדות הם native select ו־input עם תוויות גלויות, בלי combobox מותאם. ההכרזות נעשות ב־live region אחד (`role=status`). טקסט הגוף 20px, ניגודיות טקסט 8:1 ומעלה ומסגרות 4.6:1. focus גלוי בשתי שכבות. יש תמיכה ב־forced-colors וב־reduced-motion. הפונטים מקומיים לארבעת הכתבים. מספרי קלפי, כתובות וקישורים מבודדים בכיווניות (`bdi`, `dir`).
