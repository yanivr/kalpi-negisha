# כללי ההצבעה בקלפי נגישה מיוחדת — מצב אימות

עודכן: 20.10.2026

## מצב: **מאושר** (`status: approved`, גרסה 2026-10-20.2)

הנוסח אומת מול מסמך רשמי של ועדת הבחירות המרכזית לבחירות לכנסת ה־26: [תדריך למזכיר ועדת קלפי רגילה ונגישה-מיוחדת](https://www.gov.il/BlobFolder/guide/trainingmaterials26/he/mazkir_Briefing.pdf). עמוד 8 (הגדרות) קובע שבקלפי נגישה-מיוחדת רשאים להצביע, באמצעות מעטפה חיצונית, גם בוחרים מוגבלים בניידות שאינם ברשימת הבוחרים שלה, וגם בוחרים שהתפנו ממקום מגוריהם ונשים השוהות במקלט לנשים מוכות. התנאי "הקלפי שבה רשום אינה נגישה עבורו" נשען על סעיף 68א לחוק, כפי שמובא ב"כל זכות". הנוסח על הצהרה בקלפי הוא הנוסח המצומצם שהאפיון אישר.

**ניטור:** הרענון היומי מוריד את קובץ ה־PDF הרשמי ומשווה SHA-256. בהורדה המוצלחת הראשונה נרשם בסיס. כל שינוי לאחר מכן חוסם את ההצגה עד לבדיקה אנושית.

**לא נקרא:** העמוד `26elections-info` פרק 7 ועמודי החוק במאגרים רשמיים. הם חסומים בכל ערוצי הגישה מסביבת הפיתוח (קריאה אוטומטית, Chrome, הדפדפן המובנה). פרקי ההליך המלא בתדריך (עמ' 39–54) לא התקבלו בקריאה.

העמוד הרשמי S1 (`gov.il/he/pages/26elections-info?chapterIndex=7`) והעמוד `gov.il/he/pages/accessibility_26` **לא נקראו**: הגישה אליהם חסומה מסביבת הפיתוח. גם נוסח החוק העדכני לא נקרא ממאגר רשמי.

## הנוסח המוצג (config/rules.json)

חמש נקודות: התנאי הבסיסי, מעטפה חיצונית ותעודה מזהה, הצהרה אפשרית, מפונים ונשים במקלט (לפי התדריך הרשמי), והבהרה שהאתר אינו קובע זכאות. האתר אינו מכריע ב"נכות נראית לעין" ואינו מפרט עבירות.

## איך מאשרים (צעד אנושי, חובה)

1. פתחו את העמוד הרשמי S1 ואת עמוד ההתאמות לאנשים עם מוגבלות באתר ועדת הבחירות.
2. העתיקו את הטקסט הרשמי הרלוונטי לקובץ `docs/legal/s1-official-excerpt.txt`.
3. השוו אותו לנקודות ב־`config/rules.json` (שדה `texts.he`). אם יש הבדל מהותי, תקנו את הנוסח בכל ארבע השפות והעלו את `version`.
4. הריצו:
   ```
   npm run rules:approve -- --excerpt docs/legal/s1-official-excerpt.txt --start "<המילים הראשונות של הקטע>" --end "<המילים האחרונות>" --reviewer "<שם הבודק>"
   ```
   הפקודה שומרת hash של הקטע הרשמי. מכאן ואילך הרענון היומי בודק שהקטע לא השתנה, ושינוי בו **חוסם** את ההצגה עד לבדיקה חוזרת.
5. העבירו את `state/state.json` המעודכן לענף `data-state` (או הריצו את ה־workflow), ובנו מחדש.
