# פרטיות — מה האפליקציה עושה בפועל

עודכן: 20.10.2026. התיאור נבדק בבדיקת e2e אוטומטית (`tests/e2e/app.spec.ts`, הבדיקה "privacy") ובבדיקה סטטית של החבילה (`scripts/check-bundle.ts`).

| נושא | התנהגות |
| --- | --- |
| קלט | בחירת יישוב, שם רחוב ומספר בית (לא חובה). אין שם, ת"ז, טלפון, תאריך לידה או מידע רפואי |
| אחסון | הכתובת נשמרת ב־RAM של העמוד בלבד: אין localStorage, sessionStorage, IndexedDB, cookie או service worker. נבדק בדפדפן אחרי חיפוש |
| כתובת העמוד | הנתיב מכיל רק את השפה ואת שם הדף (למשל `/ru/privacy/`). הכתובת שהוזנה לא מופיעה בנתיב, ב־query או ב־hash |
| בקשות רשת | אחרי טעינת האתר אין בקשות מחוץ לדומיין. נבדק: בחיפוש לפי יישוב יש 0 בקשות חיצוניות |
| חיפוש רחוב | מתבצע כולו בדפדפן. הדפדפן מוריד מהאתר עצמו את קובץ הרחובות של היישוב שנבחר (`data/geo/<סמל>.json`), כך שהשרת יודע לכל היותר איזה יישוב נבחר. הרחוב ומספר הבית לא נשלחים לשום מקום. אין שירות גיאוקודינג חיצוני. נבדק: בחיפוש לפי רחוב יש 0 בקשות חיצוניות (e2e "street search sends nothing over the network") |
| ניווט | קישורי Waze ו־Google Maps כוללים את יעד הקלפי בלבד, בלי נקודת מוצא, עם `rel="noopener noreferrer"` ו־`referrerpolicy="no-referrer"` |
| מדידה ומעקב | אין analytics, פיקסלים, הקלטת סשן או דיווח שגיאות חיצוני |
| פונטים | הפונטים מקומיים (Noto, רישיון OFL) ואין פנייה לשירות פונטים |
| אירוח | GitHub Pages. GitHub רושמת כתובות IP לצורכי אבטחה |
| CSP | `default-src 'self'`, ו־`connect-src` מתיר רק `self` |
| לוגים ו־Issues | סקריפטי הרענון לא מקבלים כתובות משתמשים ולא כותבים אותן. אין Issues אוטומטיים |

## מה נשמר במאגר הציבורי

- קוד.
- `state-seed/` ו־ענף `data-state`: snapshot נגזר מהקבצים הרשמיים (מקומות עם קלפי נגישה מיוחדת: שם המקום, כתובת, מספרי קלפי, הוראות גישה, קואורדינטות), יחד עם hash של הקבצים, דוח בדיקות ויומן ניסיונות. אין מספרי בוחרים ואין מידע אישי.
- הקבצים הגולמיים **אינם** נשמרים (`*.xlsx` ב־`.gitignore`).
